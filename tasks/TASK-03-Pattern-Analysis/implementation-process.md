## Implementation Process

### [2026-11-16 09:18] 初始技術決策：無第三方套件依賴之 RFC 2083 Paeth PNG 底層解碼器與多假說探勘
* **環境限制與工程決策**：
  在解析 `2026 Q4 面試前考題 V1.pptx` 第 4 頁之內嵌圖片 `slide4_image1.png` 時，發現執行環境為純標準庫 Python 3.12（未安裝 `Pillow` / `OpenCV`）。為確保專案具備 **「零脆弱外部依賴（Zero Fragile Dependencies）」** 之高可移植性，我們決定不要求安裝外部套件，直接以標準庫 `struct` 與 `zlib` 撰寫符合 **RFC 2083 標準的純 Python PNG 解碼器 (`src/png_decoder.py`)**，完整實作 `None (0)`, `Sub (1)`, `Up (2)`, `Average (3)`, `Paeth (4)` 五種掃描線差分濾波還原演算法。
* **AI Agent 多假說科學探勘歷程**：
  還原出 $9 \times 5$ 四色矩陣（`R, Y, G, B`）後，Agent 連續執行多組統計腳本進行假說檢驗：
  1. *假說 A（一維環狀 $\pm 1$ 階梯漫步）*：窮舉 $4! = 24$ 種顏色映射檢查相鄰格差值是否恆為 $\pm 1$ $\to$ **結果為否，予以排除**。
  2. *假說 B（正交四著色零衝突 Proper 4-Coloring）*：檢查全部 36 條水平邊與 40 條垂直邊（共 76 條正交邊）之同色相鄰次數 $\to$ **結果嚴格為 `0 次`（確立為核心硬性規則一）**！
  3. *假說 C（局部區塊鏡像對稱）*：檢視各欄關係，發現自 `Row 2` 至 `Row 8` 連續 7 列的第 2 欄與第 4 欄 100% 相同（`Col 2 == Col 4`），構成 `B-G-B`, `R-Y-R` 等三明治回文結構；而前兩列 `Row 0, Row 1` 則為 `(G, Y)` 與 `(Y, G)` 交叉互補 $\to$ **確立為核心規則二**！
  4. *假說 D（全域配額、棋盤奇偶平衡與方向異向性）*：計算得 Shannon 熵達 `1.9904 bits`（逼近理論上限 `2.0 bits`）、西洋棋盤 `(r+c)%2` 奇偶格中 `R` 與 `Y` 各為完美的 `5 : 5`，且水平方向偏好同色系轉移（`B-G` 與 `R-Y` 佔 `58.3%`）、垂直方向偏好跨色系轉移（佔 `72.5%`）$\to$ **確立為規則三、四、五**！
  5. *假說 E（與題目一排班問題之跨題同構性）*：5 欄恰好對應 `Mon ~ Fri`、4 色對應 4 位員工、9 列對應 9 週，完美構成「禁止連續兩天上班（水平不同色）且禁止同一星期幾連續兩週同一人值班（垂直不同色）」之輪班表 $\to$ **確立為規則六**！

### [2026-11-16 10:27] 追加紀錄（源於人類工程師對語言效率之質疑）：增建 C11 `xorshift64*` + Lemire 無除法百萬次蒙地卡羅引擎
* **技術決策演進**：
  為將蒙地卡羅隨機洗牌檢定規模從 50,000 次擴大 20 倍至 **1,000,000（一百萬）次**，同時將耗時壓縮至百毫秒內：
  1. 在 Python 端預先將 76 條邊的端點一維索引編譯為不可變 `edges_tuple`，耗時由 `95 ms` 降至 `68 ms`。
  2. 新增 C11 原生引擎 `Q3_PatternAnalysis/src_native/fast_monte_carlo.c`：初版使用 `xorshift64*` 搭配 `% (i + 1)` 除法取餘數，百萬次耗時 `296.37 ms`；隨即引進 **Daniel Lemire 無除法範圍映射演算法（Fast Range without Division）**，以單週期 64-bit 乘法與右移 `((uint64_t)rnd32 * (uint64_t)(i + 1U)) >> 32` 取代昂貴的 30 週期 `idiv` 指令，使百萬次洗牌耗時大幅降至 **`105.2 ~ 174.3 ms`（每 5 萬次僅 `5.26 ~ 8.72 ms`）**！
