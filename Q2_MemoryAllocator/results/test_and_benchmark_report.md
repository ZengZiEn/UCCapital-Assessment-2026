## 4. 效能基準測試 (`benchmark_malloc.exe`) 實測結果對比

```text
========================================================================
   UC Capital 題目二：標準 malloc vs. myMalloc 實測效能基準測試套件
========================================================================

【場景 1：題目核心情境 — 單一 10,000 * sizeof(int) (40 KB) 反覆配置與釋放 1000000 次】
  - 標準 C malloc/free 耗時 :    91.42 ms (吞吐量:  1093.82 萬次/秒)
  - 自訂 myMalloc/myFree 耗時:     3.48 ms (吞吐量: 28748.85 萬次/秒)
  => 效能加速倍率 (Speedup)  : 26.28 倍 (節省 96.2% 執行時間)

【場景 2：批次高峰負載 — 同時配置 64 個 10,000 * sizeof(int) 陣列 × 10000 輪 (共 640000 次)】
  - 標準 C malloc/free 耗時 :   118.18 ms (吞吐量:   541.57 萬次/秒)
  - 自訂 myMalloc/myFree 耗時:     4.39 ms (吞吐量: 14564.65 萬次/秒)
  => 效能加速倍率 (Speedup)  : 26.89 倍 (節省 96.3% 執行時間)

【場景 3：混合大小動態配置 — 128B ~ 4096B 不規則區塊配置與合併 500000 次】
  - 標準 C malloc/free 耗時 :    16.88 ms (吞吐量:  2961.28 萬次/秒)
  - 自訂 myMalloc/myFree 耗時:     2.36 ms (吞吐量: 21194.52 萬次/秒)
  => 效能加速倍率 (Speedup)  : 7.16 倍 (節省 86.0% 執行時間)
```
