Stage 1 考題逆向解析指示先全面檢查 PPTX 考題簡報並提供分析，不貿然動手寫 code。解壓 PPTX XML 提取三題文字與第 4 頁 PNG；於無 PIL 環境下手寫 RFC 2083 Paeth 解碼器還原 9×5 色塊矩陣。精準鎖定三題核心與 Excel 四色表結構
Stage 2 SDLC 與開源調研要求按軟體工程流程建立清晰目錄（分析/日誌/架構/計畫/測試），並搜尋網路與 GitHub 類似做法。透過 search_web 檢索優式資本面試討論、OR-Tools、C Slab/Pool 與 TLSF；探測定位本機 MSVC 14.44 編譯器。建立三題 100% 對稱之五階段工程目錄
Stage 3–4 實作與實證把關強制規定「每一題做完後要實際跑過，才整理圖表 PDF 報告」（實證主義防線）。實機編譯執行三題測試；審查消除 Q3 卡方檢定硬編碼常數改為動態統計，並設計即時擷取實測 JSON 之 SVG 圖表引擎。修正 Q1 34 解枚舉與 Q2 4MB VirtualFree 卸載邊界
Stage 5 跨語言極致最佳化主動質疑：「做之前的語言選擇是否影響執行效率？確定效率最好了嗎？」要求檢索國內外討論並重新最佳化。導入 Stockfish Bitboard/SWAR 撰寫 Q1 C11 引擎；將 Q2 Arena 升級為顯式雙向自由串列；導入 Lemire 無除法撰寫 Q3 C11 引擎。Q1 單解達 17.0 ns (快800×)；Q2 加速 26×~51×；Q3 百萬次模擬 174.3 ms
Stage 6–7 日誌稽核與透明揭露要求每筆修改寫入日誌、逐字核對 PPTX 題目完備性、收斂目錄，並誠實揭露 AI Agent 協作脈絡。建立 DEVELOPMENT_LOG.md；補齊 Q1 n=50 測試與 Q3 Row 9 預測器；收斂至 docs_and_tools/ 並更新雙 PDF。18 項單元測試 100% 通過，完整展現人機協同工程範式
